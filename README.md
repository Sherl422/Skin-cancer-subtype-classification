Skin Cancer Subtype Classification

CNN-based skin cancer subtype classification using TensorFlow and transfer learning on the HAM10000 dataset. The project performs image preprocessing, augmentation, training, and evaluation to classify dermoscopic images into multiple skin lesion categories.

Features
Image preprocessing and augmentation
Transfer learning using deep learning models
Multi-class skin lesion classification
Model evaluation and accuracy analysis

Technologies Used
Python
TensorFlow / Keras
NumPy
Pandas
Matplotlib
Dataset

HAM10000 Dataset:
Human Against Machine with 10,000 dermoscopic images.

Results

Achieved high classification accuracy using transfer learning and regularization techniques.

File
skin_cancer_subtype_classification.ipynb — Complete notebook containing preprocessing, training, and evaluation.
